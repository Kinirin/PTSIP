# PTSIP Specification 0.3.7-draft — WU-12 Final Freeze

> **State:** Active draft family
> **Immutable normative snapshot:** `3c47816770d194ae42f98faedc911d980db0e62a`
> **Canonical source:** `https://github.com/Kinirin/PTSIP`

## Normative composition

`0.3.7-draft` remains additive over the mature `0.3.6-draft` primary lifecycle
ownership and Responsibility Map v2 model. It does not create a lifecycle
classification or reintroduce historical PTSIP `TOOLCHAIN` as a canonical alias.

The WU-12 snapshot includes the inherited normative documents, the Project
Profile transition companion, synchronized public/embedded schemas and registry,
and the current explicit `pp.1.01` Specification-binding contract.

## WU-12 binding additions

- a current Project Profile declares `family`, canonical `source`, and immutable
  `revision` independently from `ptsip.version`;
- Project Profile and Specification capabilities are independent,
  operation-aware authorities;
- generic validation does not require every binding to equal one Tool-global
  revision and does not use historical migration bridges as a lookup service;
- malformed or unsupported family/source/revision combinations fail closed;
- supported binding, migration capability, and repository adoption remain
  separate authorities;
- the `0.3.6-draft -> pp.1.01` identity-only bridge materializes the historical
  family while preserving architecture semantics and the existing source/revision.

## Registered migration rules

The canonical and embedded registry copies now identify `0.3.7-draft` and
register `PTSIP-MIG-004` through `PTSIP-MIG-015`, whose normative headings remain
in `spec/PTSIP-DRAFT-PROFILE-TRANSITION.md`.

## Immutable binding rule

The freeze commit deliberately contains no literal self-SHA. Tool, root profile,
maintained examples, release verification, and release notes bind backward to
`3c47816770d194ae42f98faedc911d980db0e62a` in later commits.
