# PTSIP Tool


Tool 0.3.8b1 is the owner-authorized beta release for exercising API-token
publication through the single `tooling-release.yml` workflow. The uploaded
Tool files are built and verified by the separate registered `tooling-test.yml`
mode, then consumed unchanged by publication.

### Distribution

- The Tool version is declared in root `pyproject.toml`; its runtime constant is
  a checked projection of that declaration.
- Publication uses the `PYPI_API_TOKEN` Environment Secret in GitHub's `pypi`
  environment. The owner confirmed that this token is scoped to the existing
  `PTSIP` project, so this run publishes the Tool only.
- Existing Profile `pp.1.02` and all seven engine versions remain unchanged in
  the Package composition. This release does not claim engine PyPI publication.
- Package numeric base `0.3.8` is preserved. The composition identity is calculated
  from the observed artifacts and recorded after successful publication.
- Tool 0.3.8a6 and prior published distributions remain immutable.

### Consumer compatibility

This release preserves existing public APIs and engine contracts. Independent
engine installation and consumer authority admission retain their existing
contracts. No runtime activation or consumer authority is inferred from publishing
the Tool.

### Verification

Windows x64 and Linux x64 Tool build, wheel metadata/license checks and isolated
installation are required through the registered release mode. macOS is opt-in.
Actual run IDs and file digests are retained in the shipping manifest and the
developer work-unit execution record, rather than hard-coded as future PASS claims.
