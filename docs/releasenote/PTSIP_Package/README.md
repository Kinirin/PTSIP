# PTSIP Package release history

New Package composition records use `<major>.<minor>.<micro>.<SHA6>.md`.
The numeric base changes only by explicit approval; component publication
refreshes the composition mapping. A base-only installation selector chooses
the latest successful snapshot, while an exact suffix pins its recorded snapshot.

The historical Specification notes in this folder were preserved by the
approved folder rename. Their content remains historical Specification evidence
and does not establish historical Package publication.

Package, Tool, Profile and each engine remain independently versioned.
