# PTSIP Specification 0.1.0-draft Release Notes

**Status:** Historical initial public Specification draft  
**Date:** 2026-08-07

This document preserves the initial public PTSIP Specification draft history after migration away from the root `CHANGELOG.md` file.

## Initial draft package

- defined the PTSIP name and scope;
- defined Product, Toolchain, and Neutral Contract classifications;
- established the principle **Purpose Before Reuse**;
- defined dependency, packaging, build, lifecycle, common-package, contract, and exception rules for the initial draft model;
- added the governance and conformance model;
- added the reference architecture and adoption guide;
- added the machine-readable registry and project-profile schema;
- added the coding-agent contract;
- added ADR-0001.

This draft is historical. Later `0.2.0-draft` snapshots changed and clarified several semantics while preserving the principle that exact normative identity is bound to an immutable Git revision.
