# PTSIP Tool 0.3.8a6

This is the current prerelease preparation record. GitHub/PyPI publication has
not occurred. Published Tool 0.3.8a5 remains immutable.

The release specification separates publication (`tooling-release.yml`) from
registered verification (`tooling-test.yml` through `test_modes.yaml`). It admits
full Package, Tool-only, one-engine, Profiles-only and mixed selections without
coupling their independent versions.

Windows x64 and Linux x64 are required for selected native engines. macOS arm64
is opt-in. One source SHA has one grouped GitHub carrier; engine notes remain
separate versioned records. Package composition identities use an explicitly
owned numeric base and a six-character hexadecimal mapping suffix.

Tool 0.3.8a6 includes the engine installation surface added after the published
0.3.8a5 artifact. Consumer authority admission and runtime activation retain
their existing independent contracts.

Release preparation is incomplete until the exact-source selected-component
mode and distribution evidence pass. This note does not promote historical runs
or claim that unpublished PyPI engine projects are available.
