# Project Profile Contract Notes

This namespace contains Project Profile contract-version history using the independent PTSIP PP grammar:

```text
pp.<major>.<minor>
```

Project Profile contract versions are independent from Tool SemVer and from one repository's immutable Project Profile instance revision.

Current intended contract:

```text
pp.1.02
```

See [`pp.1.02.md`](pp.1.02.md) for the current semantic-migration contract.
The historical [`pp.1.01.md`](pp.1.01.md) identity-only bridge remains preserved.
