# PTSIP project agent results

This directory holds shareable evidence produced by the reusable [PTSIP project agents](../../agents/README.md). Results can be read from any repository checkout.

Save a result as Markdown under this directory. Include the producing `agent_id` from the project agent catalog, its definition path, the task, the Git commit it examined, findings with repository-relative file and contract references, verification commands and outcomes, and any open conditions. If a historical finding lacks a recoverable revision or proof, label that uncertainty. For multi-agent results, identify the producing agent for each finding.

Before committing, review the result for credentials, personal paths, private chat content, and tool logs. Record the relevant conclusions and reproducible evidence. Check any archived claim against the current revision before using it for implementation or verification.
