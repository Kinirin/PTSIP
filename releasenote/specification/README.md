# Specification Notes

This namespace contains historical and current PTSIP Specification family/revision notes.

Specification identity is independent from both PTSIP Tool SemVer and Project Profile contract versioning.

```text
releasenote/specification/<spec-note>.md
```

Historical Specification notes that previously lived directly under `releasenote/` have been relocated here while retaining their original `spec-<family>.md` basename. This preserves their historical naming and avoids collision with the canonical new-generation `0.3.7-draft.md` WU-12 final-freeze record.

| `0.1.0-draft` | Historical initial public draft | [`spec-0.1.0-draft.md`](spec-0.1.0-draft.md) |
| `0.2.0-draft` | Historical experimental draft family | [`spec-0.2.0-draft.md`](spec-0.2.0-draft.md) |
| `0.3.3-draft` | Historical draft record | [`spec-0.3.3-draft.md`](spec-0.3.3-draft.md) |
| `0.3.4-draft` | Published Tool 0.3.5 baseline family | [`spec-0.3.4-draft.md`](spec-0.3.4-draft.md) |

The family label alone is not immutable normative identity. Exact normative claims must remain bound to the applicable immutable Specification revision.
