# Tool Release Notes

This namespace contains new-generation PTSIP Reference Tool release records.

Tool release versions use package SemVer and are independent from Project Profile contract versions and Specification family/revision identity.

```text
releasenote/tool/<tool-version>.md
```

Historical flat Tool release-note paths remain in place under `releasenote/` and are not bulk-moved.
